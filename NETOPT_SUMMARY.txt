1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
`netopt` is a high-performance network cabling optimization and resilience
engine implemented in pure C++20 with standard library features only. It models
computer and telecommunication networks as undirected, weighted graphs and
computes optimal Minimum Spanning Trees (MST) and Minimum Spanning Forests (MSF)
using:
  - Kruskal's Algorithm (with Disjoint Set Union by size and path halving)
  - Prim's Algorithm with an Indexed 4-Ary Min-Heap (O(E log4 V))
  - Prim's Dense Algorithm (O(V^2))
  - Strict composite ordering (cost, edge_id) guaranteeing 100% identical edge
    sets across all algorithms.
